差距分组

① 完全缺页（6 个）

  • Register 注册页
  • Nar1Import NAR1 导入
  • ResultsTimetable 业绩时间表
  • AdminPanel 管理后台
  • Settings 设置
  • Search / GlobalSearch 全局搜索

② 仍有缺口（2 项写能力）

  • Templates → 缺编辑（仅只读，Schema 驱动引擎，富文本编辑器较复杂）
  • CompanyDetail → 缺 Equity 股权图 / Registers 登记册 Tab

建议优先级

  1. 剩余写能力：Documents 上传 + ComplianceRules/Templates 编辑 + Calendar 事件 CRUD + CompanyDetail Equity/Registers Tab。当前 6 个核心模块已可写。
  2. Settings + 全局搜索——体验补齐，搜索对 59 家公司/19 人员尤为必要。
  3. Nar1Import / ResultsTimetable / AdminPanel——低频管理功能，可后做。
